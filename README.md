African Market OS provides market intelligence, the Minimum Viable Relationships (MVR) framework, practical playbooks, and the MVR API for humans and AI agents operating in high‑context African markets. The API computes relational‑readiness scores, offering sandbox access and commercial plans, and is documented with OpenAPI, llms.txt, and agent tools.
